# Privacy

Cadence collects nothing. It has no account, no analytics, no ads and no network access (the app does not even request the internet permission).

Your tasks, focus history and settings are stored only on your phone. Backups are files you create yourself, or a folder you choose.

## Permissions

| Permission | Why |
| --- | --- |
| Notifications | Show reminders |
| Run at startup | Re-arm reminders after a reboot |
| Vibrate | Reminder vibration |
| Display over other apps | The priority card (optional) |
| Ignore battery optimisations | Keep reminders on time (optional) |
| Read and write calendar | Show phone-calendar events and add tasks to it (optional) |
| Microphone | Voice input for new tasks (optional) |

Voice input is handled by your phone's own speech service, not by Cadence. Cadence only receives the text.
